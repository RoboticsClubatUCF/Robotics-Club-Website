# OrcaSlicer icons

These SVG files are unmodified artwork from OrcaSlicer 2.4.2's resources/images.
Source: https://github.com/OrcaSlicer/OrcaSlicer/tree/v2.4.2/resources/images
Pinned Git tree: 8500fcdccaa10b5099ac20d252af3a7c560046f1

OrcaSlicer and its contributors provide this artwork under GNU AGPL version 3.
The accompanying LICENSE.txt is copied from the same upstream release.
The website renders the original SVG alpha shapes as CSS masks so its theme tokens
control the displayed color; original SVG files and their metadata are preserved.

The toolbar's Add/Copy/Delete actions use toolbar_open/instance_add/instance_remove;
these represent adding a model, adding an instance and removing an instance.
The home shape comes from monitor_axis_home_icon; it resets the website's view.
